# ADR-0005: Independent deterministic Agent Quality Kit

Status: Accepted for M5 prototype

## Context

Reusable quality tooling needs to work in arbitrary Python agent applications, not only projects generated by AET. High-cost or stochastic LLM evaluation is unnecessary for basic tool flow regressions.

## Decision

Package `aet-agent-quality` as a separate, installable distribution under `packages/agent-quality-kit`. Its core uses only the Python standard library and exposes:

- explicit `ToolTrace` capture of tool invocation names, arguments, success/failure status;
- assertions for call counts, exact argument matching, ordering, and allowlist membership;
- lightweight top-level output-field type contracts and strict JSON encoding checks;
- an optional `pytest` fixture auto-registered through a `pytest11` entry point.

Put the generated LangGraph sample integration in `examples/quality-kit-demo`, outside the standalone package. Test package installation from both editable source and a built wheel in CI.

## Consequences and limits

This package is deterministic and does not evaluate language-model correctness, hallucination rate, safety, latency, or retrieval quality. Tool calls are only captured when callers explicitly use `ToolTrace`; instrumentation is not automatic. Argument snapshots can contain secrets if developers record them; test data must be synthetic or approved. No external services are needed for CI.
