# __PROJECT_NAME__

Generated by Agentic Engineering Toolkit (M1). This is a **local-first demonstration**, not a production agent or an LLM-integrated assistant.

The generated FastAPI application contains a LangGraph workflow with deterministic intent routing and a synthetic order-status tool. It performs **no model inference and no network API calls at runtime**. Project dependencies must be installed before first use; no credentials or WSL are required.

## Requirements

- Python 3.11+

## Setup

```powershell
python -m pip install -e ".[dev]"
python -m pytest -q
python -m uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs to try the API.

## Examples

- `GET /health` returns `{"status": "ok"}`.
- `POST /invoke` with `{"question": "hello"}` returns a mock response with `tool_used: null`.
- `POST /invoke` with `{"question": "order status ORD-1001"}` returns `{"answer": "Demo order ORD-1001 status: shipped.", "tool_used": "get_order_status"}`.
- `POST /invoke` with `{"question": "order status ORD-9999"}` exercises the unknown-record path.

Demo data is in `app/tools.py` and is entirely synthetic. Tool routing is deliberately rule-based for a reproducible test contract, not model-generated. Real LLM providers, retries, persistence, authentication, and external integrations are out of scope for M1.
