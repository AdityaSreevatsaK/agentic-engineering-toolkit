# __PROJECT_NAME__

Generated by **Agentic Engineering Toolkit M2** using the __PROVIDER__ provider.

This project is a local-first FastAPI application with a LangGraph workflow. Exact order-status commands run against an entirely synthetic local tool; ordinary prompts use the configured response provider. **Tool routing is deterministic, not LLM-directed.** This is a development reference, not a production agent.

## Requirements

- Python 3.11+
- No WSL, Docker, cloud account, or API key needed to run the default mock tests.
- For real local model responses only: install Ollama and pull a compatible model.

## Quick start (PowerShell / PyCharm terminal)

```powershell
python -m pip install -e ".[dev]"
python -m pytest -q
python -m uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs and send POST /invoke with JSON:

```json
{"question":"order status ORD-1001"}
```

The response shows the synthetic order tool, independent of provider availability.

For a regular question, mock mode returns a deterministic echo; Ollama mode requests an answer from the local API.

## Optional local Ollama mode

1. Install Ollama for Windows or your local OS.
2. From a terminal, run: `ollama pull __OLLAMA_MODEL__` (downloads model files).
3. Confirm Ollama is running on `http://127.0.0.1:11434`.
4. Copy `.env.example` to `.env` if you want to edit `AET_PROVIDER` or `AET_OLLAMA_MODEL`.
5. Restart the application and send an ordinary question to POST /invoke.

Note: A generated Ollama project defaults to `AET_PROVIDER=ollama`. To fall back to offline mock mode set `AET_PROVIDER=mock` in `.env` or your environment. A mock project can be switched to Ollama the same way.

If Ollama is offline or the model is missing, ordinary prompts return HTTP 503 with a generic diagnostic. Synthetic order-status commands continue to work. Automated tests use mocked HTTP and do not require Ollama or model downloads.

## Privacy and constraints

- The adapter accepts only loopback Ollama endpoints, not remote hosts.
- Do not expose this unauthenticated development API to the internet.
- No external model/API calls are made by the default mock provider.
- Test and fixture data are entirely synthetic.
- `.env` is excluded from Git; `.env.example` includes no secrets.
