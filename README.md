# Agentic Engineering Toolkit (AET)

**Status:** M5 prototype: independent agent quality testing added. **Privacy:** This repository must remain private.

A local-first collection of reusable Python engineering assets. The project scaffolder creates FastAPI + LangGraph applications with deterministic mock or optional local Ollama text-generation providers. **No WSL, Docker, paid API, or cloud account is required for the core test suite.**

## Asset 1: Agent Project Scaffolder

From this repository, with Python 3.11+:

```powershell
python -m pip install -e .
agentkit --version
agentkit list
agentkit new demo-agent --provider mock
agentkit doctor demo-agent
cd demo-agent
python -m pip install -e ".[dev]"
python -m pytest -q
python -m uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs. POST /invoke with `{"question":"order status ORD-1001"}` for the synthetic tool path or `{"question":"hello"}` for the deterministic mock response.

To generate an optional locally hosted text-generation example:

```powershell
agentkit new local-agent --provider ollama --model llama3.2:1b
```

Installing and running Ollama and downloading that model are separate opt-in steps for real model inference. No model is needed for automated tests.

The scaffolder also supports `agentkit doctor` for static validation and `agentkit-benchmark` for filesystem generation/validation timing. **Benchmark timings do not establish developer hours saved.** See `docs/benchmarks/study_protocol.md` for controlled trials.

## Asset 2: Standalone Agent Quality Kit (M5)

The second asset lives under `packages/agent-quality-kit` and can be installed and used independently from the scaffolder:

```powershell
python -m pip install -e "./packages/agent-quality-kit[dev]"
python -m pytest packages/agent-quality-kit/tests -q
```

Features: explicit tool trace capture, call count and order assertions, tool allowlist verification, success/error regression checks, typed output contracts, strict JSON validation and an auto-registered `agent_trace` pytest fixture. It does not require LangGraph, model APIs or the scaffolder.

See [Quality Kit README](packages/agent-quality-kit/README.md) for usage and [integration demo](examples/quality-kit-demo/test_generated_app_quality.py) for an independent consumer test against an agent generated by Asset 1.

## Automated verification

Private GitHub Actions tests the Scaffolder and generated projects, independently installs/tests the Quality Kit and its wheel, and runs integration tests across Windows and Linux with Python 3.11 and 3.12.

The examples use synthetic data only. The generated HTTP service is unauthenticated and is for local development, not public exposure. Neither asset is certified for production or enterprise security. Do not add client data or credentials to this personal repository without employer authorisation.
